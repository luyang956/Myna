# Q1: 前端项目升级Angular20构建包无法部署

## 问题描述
  用户为angular项目工程，发现自己构建的包部署时报错，缺首页文件。

## 问题定位
  - 构建脚本实现，伪代码
  ```
    for theme in themes
       npm run build --theme
  ```
 - 排查路径：
  1. 先打开构建包，查看构建内容，发现只有一个主题资源
  2. 查看日志，发现每个主题的构建都运行了，发现只有最后一个主题有资源，其他的资源在dist目录下不存在

  排查后猜想：有可能后面的构建对前面的构建存在删除等影响。

 - 联系用户构建复现问题：
  1. 在本地使用构建命令```npm run build --private```,进行第一次构建，dist目录生成private资源
  2. 第二次构建，```npm run build --public```,dist目录也产生了public资源，但是问题也出现了，第一次构建的
    private资源被删除了。

 - 这两次构建结果已经验证了我的排查猜想。但是是什么原因导致的呢？
    和用户再次确认，以前构建是正常的，这次构建前升级了Angular 20版本。

## 解决办法
  打开项目根目录下的 angular.json，找到对应的项目构建配置，在 options 中添加 "deleteOutputPath": false

## 问题思考
  1. 分析问题现象
  2. 复现问题进行推测，进一步验证问题
  3. 锁定问题根因
